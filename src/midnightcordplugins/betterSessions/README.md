# BetterSessions

Gestion des appareils Discord, noms locaux par compte, dernière utilisation et
alertes de nouvelles sessions. La vérification en arrière-plan est facultative.

Adapté du plugin [BetterSessions de Vencord](https://github.com/Vendicated/Vencord/tree/0e40e433d7aa9168f656aba733d01e761b7ca8ca/src/plugins/betterSessions),
par amia et les contributeurs Vencord, sous GPL-3.0-or-later. Les composants,
icônes et patches d'origine conservent leurs crédits ; le stockage et le suivi
des comptes ont été adaptés à Midnightcord.

Consultez le [guide des plugins](../../../docs/UTILITY-PLUGINS.md) pour l'activation
et les vérifications dans Discord.
